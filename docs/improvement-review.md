# Review improvements

The dashboard's Improvements page brings together daily findings and retrospective proposals. Your workspace role and repository access determine what you can read and decide.

Open an improvement to read its proposal and supporting evidence. Choose the available review action and give the explanation it requests. Check the latest version before deciding; if someone has changed the proposal, reload it and review again.

Follow accepted work through its linked issue and resulting pull request. Use the retrospective history to revisit reports and download their evidence. Administrators manage retrospective settings in Settings.

For access changes, see [Workspace access](workspace-access.md). For checks on the resulting work, see [Review checks and evidence](closeout.md).
