# Paws

## Platform

web

## Stack

The paws.boo landing page is built with Astro. The Paws engine is a local Bun process; the existing status dashboard is a separate surface.

## Users

Developers and engineering teams who delegate implementation work from Linear and work in GitHub repositories.

## Product Purpose

Paws takes a delegated Linear issue through coding-agent implementation, Closeout verification, and a GitHub pull request workflow on the developer's machine.

## Positioning

Paws coordinates the developer's existing coding-agent sessions over ACP rather than replacing their coding tools. Linear holds the work and questions; GitHub holds code and pull requests.

## Operating Context

Developers connect Linear and GitHub, select an implementer, run prerequisite checks, and start Paws locally. The repository README contains the setup commands and links to the operational guides.

## Brand Commitments

The product is Paws. Its landing-page domain is paws.boo. The landing page includes a GitHub setup action and an on-page workflow explanation.

## Evidence on Hand

README.md documents the product workflow and setup. src/web implements the existing status dashboard.
