# Product

## Platform

web

## Product purpose

Paws runs on a developer's machine, takes delegated Linear work, drives signed-in coding agents over ACP, verifies changes with Closeout, and delivers them through GitHub.

## Users and operating context

Developers use the dashboard to monitor work, inspect runs and verification, follow questions back to Linear, configure agent profiles, and manage runners and workspace access.

## Capabilities

The dashboard supports local engine status and explicitly labeled demo data. Existing navigation, authentication, settings, execution controls, runner management, and workspace administration behavior must be preserved during the UI migration.

## Brand commitments

The product is Paws. The dashboard uses the Neobrutalism component system from https://www.neobrutalism.dev/docs, with its copy-in components, Tailwind utilities, and shared theme tokens. Light, dark, and system appearance remain available.
